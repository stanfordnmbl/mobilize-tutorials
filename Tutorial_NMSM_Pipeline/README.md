**NMSM Pipeline Webinar Preparation Instructions**

1) Download (or clone) the files in this folder to your computer in a location whee you would like to perform the tutorial.

2) Download version 1.5.2 of the NMSM Pipeline from Simtk.org:
https://simtk.org/projects/nmsm

3) Install the NMSM Pipeline files in a convenient location (with no spaces in the path name for Windows computers).
Installation instructions are available in the file "How to Install.pdf" within the nmsm-core-1.5.2 folder and on the NMSM Pipeline website:
https://nmsm.rice.edu/getting-started/installation-guide/
After you have unzipped the installation files, remove "-1.5.2" from the folder name so that it is just "nmsm-core".

Notes:
* The NMSM Pipeline GUI plugin for OpenSim currently works on only Windows computers.
* If you are a Mac user (Intel or Apple Silicon processor), you should use an Intel version of Matlab and the official release of OpenSim 4.5. Apple Silicon processors are not yet fully supported by OpenSim or the NMSM Pipeline.
* The Model Personalization tutorials work on both Windows and Mac.
* The Treatment Optimization tutorials work on both Windows and Mac, but they will run more slowly on Mac. We have not yet implemented Matlab mex files for computationally costly OpenSim API calls on the Mac.
* For both Windows and Mac users, you will not be able to run the Treatment Optimization tutorials (Tracking Optimization, Verification Optimization, and Design Optimization) without a license for GPOPS-II optimal control software for Matlab. If you would like to request a free trial license, you can contact the GPOPS-II developer directly yourself using the web link below:
https://www.gpops2.com/
